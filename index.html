🌙 Schlaf-Erinnerung für Windows

Ein kleines Python-Skript, das dich jeden Abend um 22:00 Uhr ans Schlafen erinnert.

📥 Skript herunterladen

⚙️ Einrichtung nach dem Download:

  1. Stelle sicher, dass Python auf deinem PC installiert ist.
  2. Lege die heruntergeladene Schlafenszeit.pyw an einen festen Ort auf deiner Festplatte (z. B. in einen eigenen Ordner).
  3. Mache einen Rechtsklick auf die Datei und wähle Verknüpfung erstellen.
  4. Drücke die Tastenkombination Windows-Taste + R, tippe shell:startup ein und drücke Enter.
  5. Ziehe die erstellte Verknüpfung in diesen sich öffnenden Autostart-Ordner.

Fertig! Das Programm läuft ab jetzt bei jedem Windows-Start unsichtbar im Hintergrund und meldet sich pünktlich um 22:00 Uhr.
